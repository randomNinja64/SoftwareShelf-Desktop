Release Notes 1.3.0:
- Added variable thread count to aria2 mode
- Added ZIP download option
- aria2 mode now enabled by default
- Automatic mode improved (now auto-highlights all except sqlite, xml, image, and torrent files)
- Download button no longer enabled when no items selected
- Search button now aligned with search box

Release Notes 1.3.1:
- Fixed visual bug on downloads tab
- Fixed bug where aria2 would not enable

Release Notes 1.4.0:
- Added rating system
- Prevented restricted access items from showing in search results
- Reduced ZIP file availability limit to 40GB (Archive.org limitation previously incorrectly implemented)
- Refactored ArchiveHandler (Optimization)
- Search UI overhaul
- ZIP files now download to the downloads folder, no subdirectory.

Release Notes 1.4.5:
- Added All type option
- Added button to get latest uploads for selected type
- Added error handling in the event that Archive.org redirects your download to an HTTPS link
- Added filter to downloads menu
- Added info (Creator, Publication Year, Topic) above description
- Refactored some MainForm code relating to search handling.

Release Notes 1.5.0:
- Added option to enable/disable torrent processing in Aria2 mode
- Added ability to view user reviews from Archive.org using the "Reviews" button.
- Fixed bug with canceling downloads (selected item in list is now cancelled rather than the first one)
- Fixed subfolder handling in Archive.org items so that files are downloaded to the appropriate subfolder, rather than downloading all files to the root folder
- Improved alignment of settings controls in the Downloads tab
- Improved optimizations for singlethreaded mode (WebClient is now properly disposed of after usage)

Release Notes 1.6.0:
- Legacy and standard edition combined into one executable compatible with Windows 98 and above. (.NET 2.0 required) (Aria2 only available on XP+)
